# AppDelSur

App móvil (Android + iOS) para la comunidad del **Del Sur Rugby Club** (Esteban Echeverría, Buenos Aires).
Primer paso: bienvenida → login con Google → ¿sos jugador? → cuestionario / enrolamiento → cierre con el propósito.
Hecha por el club, para el club. Brief completo y decisiones en `CLAUDE.md`.

- Stack previsto: React Native + Expo; backend y login en Vercel (patrón Pulpo/Luganense).
